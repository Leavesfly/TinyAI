# tinyai-deeplearning-rl 技术架构文档

## 1. 模块概述

`tinyai-deeplearning-rl` 是 TinyAI 框架的强化学习核心模块，基于纯 Java 实现，覆盖从多臂老虎机到深度策略优化的完整算法谱系。模块遵循 OpenAI Gym 接口规范，以 MDP（马尔可夫决策过程）为理论基础，通过分层抽象和设计模式将算法差异点最小化，是教学与工程兼顾的强化学习实现。

**核心能力：**
- 基于值函数算法：DQN、DoubleDQN
- 基于策略梯度算法：REINFORCE、PPO
- 多臂老虎机算法：EpsilonGreedy、UCB、Thompson Sampling
- 经典控制环境：CartPole、GridWorld、MultiArmedBandit

## 3. MDP 交互模型

模块以马尔可夫决策过程为理论基础，Agent 与 Environment 形成标准交互循环：

```
初始化: s0 = env.reset()

循环（直到 done）:
  1. Agent 选择动作:   a = agent.selectAction(s)
  2. 环境执行动作:     (s', r, done) = env.step(a)
  3. 构造经验五元组:   exp = Experience(s, a, r, s', done)
  4. Agent 从经验学习: agent.learn(exp)
  5. 更新状态:         s = s'
```

**MDP 五要素映射：**

| MDP 要素 | Java 类 | 说明 |
|---------|---------|------|
| 状态空间 S | `Environment.stateDim` | 状态向量维度 |
| 动作空间 A | `Environment.actionDim` | 动作空间大小 |
| 转移函数 P | `Environment.step()` | 状态转移逻辑 |
| 奖励函数 R | `StepResult.reward` | 即时奖励信号 |
| 折扣因子 γ | `AbstractAgent.gamma` | 未来奖励衰减 |

## 5. 关键组件详解

### 5.1 Experience — 经验五元组

```java
Experience(Variable state, Variable action, float reward,
           Variable nextState, boolean done)
```

封装强化学习的一步交互数据 `(s, a, r, s', done)`，是经验回放机制的基本存储单元。`timeStep` 字段支持序列标记，用于调试与分析。

### 5.2 ReplayBuffer — 经验回放缓冲区

- **结构**：固定容量循环缓冲区，满时覆盖最旧经验
- **采样**：`sample(batchSize)` 使用 Fisher-Yates 洗牌算法（无重复采样）
- **作用**：打破时序相关性，提升样本利用率，稳定训练

```
写入:  push(exp)  →  position = (position + 1) % capacity
采样:  Fisher-Yates shuffle → 取前 batchSize 个索引
```

**PrioritizedReplayBuffer** 在此基础上引入优先级权重，高 TD 误差的经验被更频繁采样。

### 5.3 EpsilonGreedyPolicy — ε-贪婪策略

- 训练模式：以概率 ε 随机探索，以概率 1-ε 选择最大 Q 值动作
- 评估模式：纯贪婪，选择 Q 值最大动作
- `decayEpsilon(rate, minEpsilon)`：训练过程中逐步降低探索率

### 5.4 ValueBasedAgent — 模板方法核心

统一训练流程（`learnBatch`）：

```
1. computeTargetQValues(batch)  ← 子类实现（算法差异点）
2. computeCurrentQValues(batch) ← 子类实现
3. loss = MSE(target, current)
4. loss.backward() → optimizer.update()
5. trainingStep % targetUpdateFreq == 0 → updateTargetNetwork()
6. policy.decayEpsilon(0.995f, 0.01f)
```

目标网络更新（Hard Update）：`ModelUtil.copyWeights(onlineModel, targetModel)`

### 5.5 TrainingStatistics — 统一训练监控

集中管理损失、奖励、更新次数等训练指标，避免各 Agent 重复实现统计逻辑。通过 `toMap()` 提供标准化输出接口。

## 6. 算法实现详解

### 6.1 DQN — Deep Q-Network

**目标Q值：**
```
y = r + γ × max_a' Q_target(s', a')    （非终止）
y = r                                    （终止）
```

**网络结构（通过 ModelUtil.createQNetwork 创建）：**
```
Linear(stateDim → hidden[0]) → ReLU
Linear(hidden[0] → hidden[1]) → ReLU
...
Linear(hidden[-1] → actionDim)
```

**关键创新：** 目标网络 + 经验回放，解决训练不稳定问题。

### 6.2 DoubleDQN — 解决过估计

**目标Q值（与 DQN 的唯一差异）：**
```
a* = argmax_a' Q_online(s', a')          （在线网络选动作）
y  = r + γ × Q_target(s', a*)           （目标网络评估）
```

通过解耦动作选择与动作评估，消除 DQN 系统性高估 Q 值的偏差。

### 6.3 REINFORCE — 蒙特卡罗策略梯度

**算法流程：**
```
1. 收集完整回合: [(s0,a0,r1), (s1,a1,r2), ..., (sT,aT,rT)]
2. 计算折扣回报: G_t = r_t + γ·r_{t+1} + γ²·r_{t+2} + ...
3. 可选基线:     A_t = G_t - V(s_t)
4. 策略损失:     L = -Σ log π(a_t|s_t) × G_t（或 A_t）
5. 反向传播更新策略网络参数 θ
```

`useBaseline=true` 时同步训练价值网络 V(s)，以均方误差为损失减少策略梯度方差。

### 6.4 PPO — 近端策略优化

**裁剪目标函数：**
```
r_t(θ) = π_θ(a_t|s_t) / π_θ_old(a_t|s_t)
L_CLIP = E[min(r_t × A_t, clip(r_t, 1-ε, 1+ε) × A_t)]
```

**特有参数：**
- `clipEpsilon`：策略更新幅度限制（典型值 0.2）
- `ppoEpochs`：每批数据的重复优化轮数
- `valueModel`：独立价值网络，提供优势函数估计

### 6.5 多臂老虎机算法对比

| 算法 | 选择策略 | 核心公式 |
|------|---------|---------|
| EpsilonGreedy | ε 概率随机，否则取最大均值 | Q(a) += α(r - Q(a)) |
| UCB | 置信上界最大 | UCB(a) = Q(a) + c√(ln N / n(a)) |
| ThompsonSampling | Beta 分布采样 | Beta(α_a + wins, β_a + losses) |

## 8. 设计模式应用

### 8.1 模板方法模式

`ValueBasedAgent.learn()` 定义 Value-Based 算法的通用训练骨架，子类通过实现 `computeTargetQValues()` / `computeCurrentQValues()` 两个钩子方法注入算法差异：

```
ValueBasedAgent.learnBatch()
    ├── computeTargetQValues()  ← DQNAgent / DoubleDQNAgent 差异点
    ├── computeCurrentQValues() ← DQNAgent / DoubleDQNAgent 差异点
    ├── MSE Loss + backward()   ← 公共逻辑
    └── updateTargetNetwork()   ← 公共逻辑
```

### 8.2 策略模式

`Agent.selectAction()` 支持运行时切换动作选择策略，`Policy` 抽象类定义标准接口：`selectAction()`、`getActionProbabilities()`、`getLogProbability()`。

### 8.3 组合模式

神经网络通过 `Sequential` 容器组合 `Linear`、`ReLU` 等基础 Block，`ModelUtil.createQNetwork()` 封装了网络构建逻辑。

### 8.4 工厂模式

`ModelUtil` 扮演工厂角色，统一创建 Q 网络实例，屏蔽网络结构细节，降低 Agent 与网络实现的耦合度。

## 9. 数据流图

### Value-Based 算法数据流

```
Environment.step(action)
        │
        ▼ StepResult(s', r, done)
Experience(s, a, r, s', done)
        │
        ▼ push
ReplayBuffer
        │
        ▼ sample(batchSize)
Experience[] batch
        │
        ├─► computeTargetQValues → targetModel.forward(s') → maxQ / argmax
        │
        ├─► computeCurrentQValues → model.forward(s) → Q(s,a)
        │
        ▼
MSELoss(target, current) → backward() → optimizer.update()
        │
        ▼ (每 targetUpdateFreq 步)
ModelUtil.copyWeights(model → targetModel)
```

### Policy-Based 算法数据流

```
Episode 采集: [(s0,a0,r1), ..., (sT,aT,rT)]
        │
        ▼ 回合结束后
计算折扣回报 G_t = Σ γ^k × r_{t+k}
        │
        ▼ （可选）
基线估计 V(s_t) → 优势 A_t = G_t - V(s_t)
        │
        ▼
策略损失 L = -Σ log π(a_t|s_t) × A_t
        │
        ▼
backward() → policyOptimizer.update()
```
